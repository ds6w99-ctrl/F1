# مقارنة: قسم «إزالة التطبيقات» في F1 مقابل Bulk Crap Uninstaller (BCU)

> المرجع: [BCUninstaller/Bulk-Crap-Uninstaller](https://github.com/BCUninstaller/Bulk-Crap-Uninstaller)
> وتوثيقه: [Leftover Cleanup](https://mintlify.wiki/Klocman/Bulk-Crap-Uninstaller/features/junk-cleanup)،
> [Application Detection](https://mintlify.wiki/Klocman/Bulk-Crap-Uninstaller/features/application-detection)،
> [Uninstall Process](https://mintlify.wiki/Klocman/Bulk-Crap-Uninstaller/guide/uninstall-process).
> مقارنة الكود الفعلي في F1 (`src/SystemCore.Infrastructure/Uninstaller/*`، `UninstallerViewModel.cs`).

## أرقام فعلية على جهاز الاختبار

| المصدر | العدد |
|---|---|
| مدخلات سجل Uninstall (HKLM 64 + HKLM 32 + HKCU) | **204** منها **166** مكوّن نظام/تحديث و**159** MSI |
| مدخلات فيها UninstallString | 190 |
| مدخلات فيها QuietUninstallString | **14** فقط |
| حزم MSIX (المستخدم الحالي) | 90 |
| مكتبة Steam | موجودة |

الفارق في `RegistryApplicationProvider` أن F1 يستثني من العرض المكوّنات المحمية/MSI غير المتحقق منها،
بينما BCU يعرض كل شيء تقريبًا مع تصفية اختيارية.

## 1) اكتشاف التطبيقات

| البند | BCU | F1 | الحكم |
|---|---|---|---|
| السجل (HKLM/HKCU × 32/64) | ✅ | ✅ (`RegistryApplicationProvider`) | متعادل |
| MSI عبر MSI API | ✅ (EnumProducts) | ✅ (`MsiApplicationProvider`) | متعادل |
| MSIX/Store | ✅ | ✅ (إزالة مستخدم حالي فقط) | متعادل |
| **فحص أقراص بحثًا عن تطبيقات غير مسجلة** | ✅ `DirectoryFactory` — يكتشف portable/orphaned | ❌ **غير موجود** | **فجوة كبيرة** |
| **التطبيقات المحمولة (portable)** | ✅ | ❌ (فقط عبر Cleaner/الملفات) | **فجوة** |
| Steam / Epic / EA / Ubisoft / Battle.net | ✅ كتطبيقات عادية + Steam للألعاب | ✅ (`SteamGameLibraryProvider`, `EpicGameLibraryProvider` — ألعاب فقط) | F1 أعمق للألعاب، أضعف للبرامج |
| Windows Features (الميزات الاختيارية) | ✅ | ❌ | **فجوة** |
| إزالة التكرار بين المصادر | ✅ `MergeResults` | ✅ (مدمج في Inventory + MSIX/MSI) | متعادل |
| إثراء البيانات (الناشر، الأيقونة، الحجم، التواقيع) | ✅ واسع | ✅ جزئي (أيقونات عبر `ApplicationIconReader`) | BCU أوسع |

| إزالة MSI | ✅ | ✅ (`msiexec /x {code}`) | متعادل |
| إزالة MSIX | ✅ | ✅ (مستخدم حالي) | متعادل |

| **إزالة مجمّعة (Bulk)** | ✅ ✅ جوهر المنتج (تحديد متعدد + طابور) | ❌ **عنصر واحد في كل مرة** | **فجوة جوهرية** |

| البند | BCU | F1 | الحكم |
|---|---|---|---|
| فحص آلي بعد الإزالة | ✅ | ✅ | متعادل |

| حماية البيانات الشخصية (consent صريح) | ⚠️ تصنيف فقط | ✅ **موافقة صريحة لكل عنصر** | **F1 أقوى** |

| **كشف اليتامى في Program Files (Orphan Scanner)** | ✅ | ❌ | **فجوة** |
| حماية المسارات المحمية | ✅ | ✅ `LeftoverSafety` (شجرة أوسع) | متعادل |
| سقف لكل مُرساة | ✅ حدود | ✅ (300/مُرساة، F1-003) | متعادل |
| فحص مستقل بدون إزالة | ✅ Standalone scan | ❌ (الفحص مرتبط بإيصال إزالة) | فجوة |
| تصدير نتائج المخلفات | ✅ | ❌ | بسيطة |
| إزالة مرتفعة الصلاحيات | ✅ (يعمل كأدمن) | ✅ (ElevatedHost + بروتوكول موثق) | **F1 أأمن معمارية** |

## الخلاصة

**F1 يتفوق في:** الأمان والتوريث (إيصال موثق، دليل حذف فعلي، موافقة صريحة، تحقق بالهوية، بروتوكول مرتفع الموثوقية) + العربية/RTL + الثيمات.

**F1 متأخر عن BCU في:** الإزالة المجمّعة، الإزالة الصامتة، فحص الأقراص/التطبيقات المحمولة، Windows Features، نسخ ملفات احتياطية + استعادة، كشف اليتامى، الفحص المستقل، التصدير/CLI.

## أولويات مقترحة (إن أردت اللحاق بـ BCU دون التضحية بالأمان)

1. **الإزالة المجمّعة** (طابور بعنصر واحد في كل مرة، مع تحقق مستقل لكل عنصر) — أكبر فجوة استخدام.
2. **استخدام `QuietUninstallString`** عند توفره مع خيار صريح للمستخدم — الفجوة الأرخص.
3. **نسخ احتياطي للملفات قبل حذف المخلفات + استعادة** — الفجوة الأمنية الأهم في F1 نفسه.
4. **كشف اليتامى في Program Files** كفحص مستقل (قراءة فقط) — قيمة عالية.
5. **تصدير نتائج الجرد/المخلفات** (CSV/JSON) — قيمة عالية وتكلفة منخفضة.
